¶ 一、安装 ADB 工具

选择你正在使用的操作系统。

Windows
Ubuntu
Mac
命令行
手动安装
打开 powershell（win + R -> 输入 powershell -> 回车），执行以下命令:
$u='https://docs2.listenai.com/zz/12368.ps1?shortId=CTJDD1EDe'; $p="$env:TEMP\install-adb.ps1"; Invoke-WebRequest $u -OutFile $p; powershell -NoProfile -ExecutionPolicy Bypass -File $p

预期页面：

可以通过执行命令 adb --version 来检查是否已经安装，如果已经安装本章节可以跳过

ADB 工具版本要求 1.0.41，如果低于该版本请重新安装ADB工具

下载 ADB 工具：platform-tools-latest-windows.zip

解压后，以管理员身份执行 install.bat 脚本自动配置环境变量

测试是否安装成功

打开一个新的终端，然后执行命令：adb --version

如果脚本无法成功执行，可以按照下图，手动配置环境变量：

打开终端，执行命令：
sudo apt install adb

打开终端执行命令, 安装 Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

安装ADB工具
brew install --cask android-platform-tools

¶ 二、安装 cskburn desktop

¶ 系统要求

¶ - Windows：10 或以上

¶ - Linux：Ubuntu 22.04 或以上

¶ - macOS：13.0 (Ventura) 或以上

如果系统版本过低，请先更新系统。

根据系统下载对应版本的快速烧录工具 cskburn desktop 安装包：

版本
安装包

 | Windows
 | cskburn-desktop_windows-x86_64-setup_v1.2.exe

 | MacOS_x86_64
 | cskburn-desktop_darwin-x86_64_v1.2.dmg

 | MacOS_ARM
 | cskburn-desktop_darwin-aarch64_v1.2.dmg

 | Linux_x86_64
 | cskburn-desktop_linux-x86_64_v1.2.deb

 | Linux_ARM
 | cskburn-desktop_linux-aarch64_v1.2.deb
