¶ OTA使用教程

¶ 前言

本文用于教学开发者如何把OTA更新包上传到云端。

注意： Arcs-Mini3 和 Arcs-Mini2 固件不通用，切勿混淆，区分方式请参考文档《如何区分Arcs-Mini3与Arcs-Mini2》。

请根据设备型号选择对应的固件和 OTA 更新包，勿将 Mini 固件刷入 Mini3，或将 Mini3 固件刷入 Mini。

¶ 开始之前，请先保证：

设备需要电池剩余电量超过 50% 或者 接入 USB 供电 才会触发OTA更新

SDK 版本在 2.3.0 及以上

可通过命令 git log 查看版本，如果版本过低，请使用命令 git pull --rebase 拉取最新 SDK

已经根据文档《烧录工具安装教程》 安装了ADB工具和烧录工具。

开发板的固件已经更新到 2.3.0 版本以上，如版本过低，请参考文档《Arcs-Mini 固件烧录教程(ADB工具)》 进行更新

¶ 一、编译SDK

请参考文档 《SDK编译教程》 编译固件

注意： Arcs-Mini2 和 Arcs-Mini3 固件不通用，切勿混淆，区分方式请参考文档《如何区分Arcs-Mini2与Arcs-Mini2》。

请根据设备型号选择对应的固件和 OTA 更新包，勿将 Mini 固件刷入 Mini3，或将 Mini3 固件刷入 Mini。

2.3.0 及以上的SDK的编译产物有：arcs-mini-v2.3.0.ota-info.txt arcs-mini-v2.3.0.ota.txz

其中，版本号可以通过修改arcs_mini/apps/arcs-mini/version 进行调整。

¶ 二、新建应用

完成注册后，访问聆思平台(LSPlatform)平台进行登录，点击应用模板中心，在简易配置标签下选择大模型语音交互模板点击添加应用按钮。给应用命名后点击确认创建应用。

¶ 三、设备接入云端应用

Arcs-mini 请参考文档《Arcs-mini 接入自建云端应用》 接入云端应用

¶ 四、上传OTA固件并发布

上传的固件版本号需要比设备的版本号更高
