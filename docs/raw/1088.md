¶ Arcs-mini 开发板更换默认人设的唤醒词 和 屏幕提示引导语的唤醒词

¶ 前言

Arcs-Mini 示例默认唤醒词是“小聆小聆”，本文主要讲解如何将唤醒词替换为自己的个性化唤醒词。

在参照本章节进行更换唤醒词之前，请确保您手头的 Arcs-mini 已经根据文档《应用功能说明》的【网络配置】章节的步骤成功配网。

¶ 更换唤醒词

¶ 一、新建应用

完成注册后，访问聆思平台(LSPlatform)平台进行登录，点击应用模板中心，在简易配置标签下选择大模型语音交互模板点击添加应用按钮。给应用命名后点击确认创建应用。

完成创建后，点击应用即可调出快速配置菜单，在配置菜单中，我们可以快速对该应用进行功能配置

¶ 二、创建唤醒词

¶ 三、 Arcs-mini 接入您的应用

请参考文档《LS26(Arcs-mini开发板) 对接云端应用》 接入云端应用

¶ 四、等待 Arcs-mini 更新唤醒词

更新结束后就可以用新的唤醒词 小红小红 唤醒

¶ 更换唤醒词的 UI

通常情况下，并不需要修改端侧代码即可实现

端侧会自动将 #唤醒词# 替换成您配置的唤醒词（比如小聆小聆或者小红小红）

¶ 禁止唤醒词更新

最后，需要禁用唤醒词自动更新功能。

禁用：adb shell kv set int user.disable_wakeword_update 1

查看：adb shell kv get int user.disable_wakeword_update

返回 flash get user.disable_wakeword_update:1 success 表示已禁用唤醒词更新

恢复默认（允许更新）：adb shell kv del user.disable_wakeword_update

擦除唤醒词（触发重新下载）：cskburn -C arcs -b 1500000 -s COMx --erase 0x00200000:2097152

注意如果禁用了唤醒词更新，擦除后不会重新下载，设备会无法唤醒
