¶ Arcs-mini 的出厂 demo 运行过程中，堆内存通常还剩余多少呢？

回答：

可以通过函数heap_summary_info()实时查看当前剩余堆内存，该函数的使用示例如下：

static void mem_check_task(void *param);
int main(int argc, char **argv)
{
    lisa_thread_attr_t mem_att = {.name = "MEM_CHECK_TASK", .stack_size = 4096 * 2, .priority = 8};
    lisa_thread_create(&mem_att, mem_check_task, NULL);
}
static void mem_check_task(void *param)
{
    while(1){
        heap_summary_info();
        vTaskDelay(1000);
    }
}

¶ Arcs-mini 如何查看设备的 MAC 地址？

打开 聆思在线串口终端 ，选择波特率为 921600

串口板连接 Arcs-mini

戳一下复位小孔，复位 Arcs-mini

复制日志，然后搜索 MAC Manager init done

如果您希望自定义 MAC 地址的话，通过修改 arcs_mini/arcs-sdk/modules/mac_manager/src/port/content/chip_id/mac_manager_content_ops_chip_id.c  文件内的 static int get(uint8_t *mac, size_t *mac_len) 函数即可。

¶ Arcs-mini 为什么每次编译固件的时候都很慢? / Arcs-mini 构建速度非常慢，怎么解决？

在 WSL2 环境下进行固件编译时，如果感觉速度较慢，一个常见的原因是 SDK 代码存放的位置不当。

问题原因：

如果将 SDK 克隆到了挂载的 Windows 硬盘路径下（例如 /mnt/d/），文件系统的读写性能会显著下降，从而导致编译变慢。

解决方案：

请将 SDK 代码移动到 WSL 系统内的原生路径下（例如 /home/workspace/），这能利用 Linux 文件系统的性能优势，从而大幅提升编译速度。
