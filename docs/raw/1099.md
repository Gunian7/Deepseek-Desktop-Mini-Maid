¶ 1. 准备模组

¶ 2. 模组飞线

按照如下要求，将相应点位通过杜邦线 及 按键 引出来。

串口烧录需要用到的点：VBAT TX0 RX0 GND；

boot按键： boot烧录按键，可以将TX0和GND短路，方便触发进入 boot烧录模式；

RST按键：reset复位按键，可以将NRESET和GND短路，方便复位；

供电：VBAT`可以供3.3V~5V

¶ 2. 进入 ROM 升级模式

进入方式：

模组侧VBAT TX0 RX0 GND点位引出的杜邦线，分别与串口转usb小板对应的管脚相连;

串口转usb小板 连接电脑;

长按 boot按键 ，再短按RST按键，松开boot按键,此时模组会进入 ROM 升级模式（没有任何提示，实际已经进入）

  

连接完成就可以使用 cskburn 烧录.

¶ 3. 开始烧录 Boot 程序及业务固件

将串口板连接开发板后，开始烧录 boot 程序及业务固件。

Linux
Windows
sudo ./cskburn_linux_amd64 -C arcs -s /dev/ttyUSB0 -b 3000000 --verify-all \
0x0 ./arcs_mini/res/boot.bin \
0x40000 ./arcs_mini/res/ap.bin \
0xF0000 ./arcs_mini/res/app-config.json \
0x100000 ./arcs_mini/res/tone.bin \
0x200000 ./arcs_mini/res/wrap.json \
0x210000 ./arcs_mini/res/esr.bin \
0x600000 ./arcs_mini/build/aiui.bin 

其中，/dev/ttyUSB0的 USB 编号可以通过命令 sudo dmesg | grep tty 查询到(通常都是用 ttyUSB0，如果识别不到再查询)

烧录成功画面

其中，DOWNLOAD_SERIAL_PORT 可以通过 windows设备管理器查看当前串口转USB小板对应的端口号，请将其设置为实际的串口端口号。

Windows查看串口端口号：

打开设备管理器：通过右键点击开始菜单（或使用Win+X快捷键），选择“设备管理器”来进入。

查找端口：在设备管理器界面中，定位并展开“端口（COM和LPT）”类别。

确认COM口号：在呈现的列表里，你将清晰地看到系统中已连接的COM口及其相应的编号。
