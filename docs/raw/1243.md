Mini3 的 PB06/PB07 在默认板级配置中用于 UART2。本示例初始化 PCA5685 时会把这两个引脚重新配置为 I2C0，因此不能同时使用外部 UART2。

¶ 1. 服务层与构建接入

PCA5685 服务位于：

apps/arcs-mini/services/service_pca5685.c

apps/arcs-mini/services/service_pca5685.h

服务在 apps/arcs-mini/services/CMakeLists.txt 中参与编译，并提供初始化、顺时针旋转、逆时针旋转和停止接口。应用启动时由 apps/arcs-mini/main.c 调用 service_pca5685_init()。

¶ 2. 按板型选择 I2C0 引脚

Mini2 保持原来的 PA05/PA04，Mini3 使用 PB06/PB07：

#define PCA5685_I2C_ADDR 0x40U
#define PCA5685_I2C_FUNC CSK_IOMUX_FUNC_ALTER8

#ifdef CONFIG_BOARD_ARCS_MINI3
#define PCA5685_I2C_PAD      CSK_IOMUX_PAD_B
#define PCA5685_I2C_SDA_PIN  6U
#define PCA5685_I2C_SCL_PIN  7U
#define PCA5685_I2C_SDA_NAME "PB06"
#define PCA5685_I2C_SCL_NAME "PB07"
#else
#define PCA5685_I2C_PAD      CSK_IOMUX_PAD_A
#define PCA5685_I2C_SDA_PIN  5U
#define PCA5685_I2C_SCL_PIN  4U
#define PCA5685_I2C_SDA_NAME "PA05"
#define PCA5685_I2C_SCL_NAME "PA04"
#endif

初始化时显式覆盖目标引脚的 pinmux，并通过 I2C0() 获取控制器：

IOMuxManager_PinConfigure(PCA5685_I2C_PAD,
    PCA5685_I2C_SDA_PIN, PCA5685_I2C_FUNC);
IOMuxManager_PinConfigure(PCA5685_I2C_PAD,
    PCA5685_I2C_SCL_PIN, PCA5685_I2C_FUNC);

s_i2c_dev = I2C0();

¶ 3. PCA5685 初始化与舵机控制

PCA5685 默认 I2C 地址为 0x40。服务按芯片初始化流程设置 MODE 寄存器和预分频值，把 16 路输出配置为约 50Hz PWM，并在启动时将所有通道设置为停止脉宽。

顺时针：约 1.3ms 脉宽。

停止：约 1.5ms 脉宽。

逆时针：约 1.7ms 脉宽。

服务把纳秒脉宽换算为 PCA5685 的 12 位计数值，再写入对应通道的 LEDn_ON/LEDn_OFF 寄存器。所有 I2C 访问通过互斥锁串行化，避免多个任务同时控制舵机时破坏总线时序。

¶ 4. 注册 MCP 工具

MCP 工具位于 apps/arcs-mini/mcp-tools/mcp_tool_pca5685.c，支持两个必填参数：

direction：cw、ccw 或 stop。

servo_id：PCA5685 通道号，范围 0~15。

MCP_TOOL_DEFINE(pca5685_control,
    pca5685_control_list,
    pca5685_control_call);

工具描述会根据板型显示 Mini2 的 PA05/PA04 或 Mini3 的 PB06/PB07，但注册名保持不变。

¶ 5. 编译验证

.\build.ps1 -S .\apps\arcs-mini -B build-pca5685-mini -DBOARD=arcs_mini
.\build.ps1 -S .\apps\arcs-mini -B build-pca5685-mini3 -DBOARD=arcs_mini3

两个板型均应生成 arcs-mini.bin、LPK、OTA 和 combined HEX。实板接线时，舵机电源建议独立供电，并务必与开发板和 PCA5685 共地。
