¶ Agent 搭建 Arcs-mini 开发环境

¶ 前言

本文演示在 Windows 环境下用 AI Agent 进行 Arcs-mini 开发环境搭建。

开始之前，本地需安装 Claude Code / Codex 等 AI 编程助手。

可参考文档《AI Agent 编程助手安装教程》安装 AI 编程助手。

 

¶ 一、搭建开发环境

以 Claude Code 为例

并根据其中 AGENTS.md 的指引完成开发环境准备。
