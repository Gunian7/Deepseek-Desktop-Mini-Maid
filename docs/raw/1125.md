¶ ADB 烧录固件时报错：error: protocol fault (couldn't read status message): Success

问题截图

问题原因

该错误通常由 ADB 工具版本过低引起。

ADB 工具更新至 1.0.41 及以上版本可解决此问题，但 Ubuntu 18.04 的 apt 源中最新版本仅为 1.0.39。

解决办法

(推荐) 更新最新版本的 ADB 工具，执行以下代码：

wget -q https://dl.google.com/android/repository/platform-tools-latest-linux.zip -O /tmp/platform-tools.zip && \
unzip -q /tmp/platform-tools.zip -d /tmp/ && \
sudo mkdir -p /usr/lib/android-sdk/ && \
sudo rm -rf /usr/lib/android-sdk/platform-tools && \
sudo mv /tmp/platform-tools /usr/lib/android-sdk/ && \
sudo ln -sf /usr/lib/android-sdk/platform-tools/adb /usr/bin/adb && \
sudo ln -sf /usr/lib/android-sdk/platform-tools/fastboot /usr/bin/fastboot && \
sudo chmod +x /usr/lib/android-sdk/platform-tools/adb /usr/lib/android-sdk/platform-tools/fastboot && \
rm -f /tmp/platform-tools.zip && \
hash -r && \
echo -e "\n安装成功！ADB版本信息：" && \
adb --version

Ubuntu 的系统版本升级至 20.04 及以上。

新版本系统的 apt 源已包含 ADB 1.0.41

使用串口烧录固件

若 ADB 烧录仍存在问题，可通过串口烧录解决，参考文档 Arcs-Mini 开发环境搭建指南

¶ 使用 cskburn 进行串口烧录时报错

报错日志：

Device not synced after baud rate change: ETIMEDOUT

Failed opening device

问题截图：

解决办法：

可能波特率超过串口板上限，可以降低波特率至 1500000 烧录。使用以下命令进行烧录：

sudo ./cskburn_linux_amd64 -C arcs -s /dev/ttyUSB0 -b 1500000 --verify-all \
0x40000 ./arcs_mini/res/ap.bin \
0xF0000 ./arcs_mini/res/app-config.json \
0x100000 ./arcs_mini/res/tone.bin \
0x200000 ./arcs_mini/res/wrap.json \
0x210000 ./arcs_mini/res/esr.bin \
0x600000 ./arcs_mini/build/aiui.bin

可能串口板损坏，更换串口板后再尝试重新烧录

¶ Arcs-mini 开发板接入电脑后怎么没有串口？

回答

Arcs-mini 接入电脑后是没有串口的，Arcs-mini是ADB设备，接入后会被识别成ADB设备。
