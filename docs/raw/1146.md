¶ 前言

本文是一篇实战教程，旨在引导你通过自定义 MCP（Model Context Protocol）工具，结合语音指令控制硬件设备。我们将以 Arcs-mini 开发板为例实现一些 mcp 工具。

Arcs-Mini2
Arcs-Mini3

目标：

当你说出“现在湿度是多少？”时，Arcs-Mini2 通过可扩展接口 PA04（SCL）和 PA05（SDA）使用 I2C0 读取温湿度信息。

当你说出“舵机顺时针旋转”时，Arcs-Mini2 通过可扩展接口 PA06 输出 PWM 方波，控制舵机顺时针旋转。

当你说出“串口发送早上好”时，Arcs-Mini2 通过可扩展接口 PA07（UART1 TX）发送“早上好”。

目标：

当你说出“现在湿度是多少？”时，Arcs-Mini3 通过可扩展接口 PA00（SDA）和 PA01（SCL）使用 I2C1 读取温湿度信息。

当你说出“舵机顺时针旋转”时，Arcs-Mini3 通过可扩展接口 PB07 输出 PWM 方波，控制舵机顺时针旋转。

当你说出“串口发送早上好”时，Arcs-Mini3 通过可扩展接口 PB06（UART2 TX）发送“早上好”；该版型在本示例中仅发送，不启用串口接收。

¶ 开始之前请先检查

¶ SDK版本

实操之前，请确保已根据文档《Arcs-Mini 开发环境搭建指南》 搭建开发环境。

本篇示例源码基于 3.0.2-m3 版本的 SDK。

可通过命令 git log 查看版本，如果版本不一致，请使用命令 git checkout mini-v3.0.2-m3 切到指定 SDK 版本。

¶ 关闭云端OTA更新

参考文档《烧录工具安装教程》安装ADB工具

执行命令 adb shell kv set int user.disable_app_update 1 关闭云端OTA更新，防止云端更新把刚烧录的固件刷掉了。

Mini3 综合示例会接管 PA00/PA01/PB06/PB07，因此不再兼容 4G EN/RST 控制，也不提供 UART2 RX/回显。
