¶ 更换唤醒词

¶ 写在前面

Arcs-Mini 示例默认唤醒词是“小聆小聆”，本文主要讲解如何将唤醒词替换为自己的个性化唤醒词。

¶ 实现流程简介

我们将通过以下步骤实现唤醒词的替换：

Step1：访问聆思语音定制服务工具，填写唤醒词后下载固件包

Step2：使用cskburn烧录工具将固件包中的唤醒资源文件烧录到开发板指定地址

Step3：重新运行示例即可体验

¶ 唤醒词替换步骤说明

¶ Step1：在语音定制平台上创建产品并填写唤醒词

访问 聆思AI语音定制平台

登录后在左侧菜单栏选择【算法资源打包】，然后在右侧点击【新增】按钮：

填写相关信息，选择【LS26系列-CHIP】，然后保存

完成产品创建后，可以在主页面中看到新创建的产品，点击其【详情】选项打开产品模型

来到新页面后，点击【快速创建】

设置唤醒词,然后点击【继续】

最后点击生成并关闭

操作成功后，固件会排队打包（大概5min），打包完成后，点击下载SDK选项

¶ Step2：打包唤醒词资源

解压从下载的 SDK 压缩包，然后从中找到对应文件

cae_esr.bin 文件（路径为Standard_product\stage1_install\res\cae_esr.bin）

wrap.json 文件（路径为Standard_product\stage1_install\res\wrap.json）

将其复制到 sdk 的 res/arcs-mini/wake_word 路径下

在 sdk 的根目录下，执行命令

python3 ./tools/romfs.py pack -i ./res/arcs-mini/wake_word/ -o ./res/arcs-mini/wake_word.bin

¶ Step3：烧录唤醒词资源

需要将刚才打包的 wake_word.bin 文件（路径为\res\arcs-mini\wake_word.bin），然后将其烧录到 0x200000

注意：请务必修改烧录地址，否则会导致运行不了

¶ Step4：禁止唤醒词更新

禁用：adb shell kv set int user.disable_wakeword_update  1

查看：adb shell kv get int user.disable_wakeword_update 

返回 flash get user.disable_wakeword_update:1 success 表示已禁用唤醒词更新

恢复默认（允许更新）：adb shell kv del user.disable_wakeword_update 

擦除唤醒词（触发重新下载）：cskburn -C arcs -b 1500000 -s COMx --erase 0x00200000:2097152

注意如果禁用了唤醒词更新，擦除后不会重新下载，设备会无法唤醒

¶ 更换 UI 里的唤醒词提示

当我们完成唤醒词的替换后，可能还希望将应用UI上的操作提示也更换为自己的唤醒词。

¶ Step1：安装ADB工具

参考文档 《cskburn烧录工具&ADB工具安装教程》 安装即可。

¶ Step2：执行命令

关闭云端更新唤醒词：

adb shell kv set int user.disable_wakeword_update 1

修改唤醒词执行命令：

adb shell kv set string sys.wakeword "xxxx"

¶ Step3：重启

执行命令

adb shell reboot
