¶ 3-查看日志

ADB 查看日志
串口日志（推荐）

基于 ADB 工具查看日志将丢失刚上电时刻的部分日志，因此更推荐使用串口，能够获取更完整的日志信息

按照文档《烧录工具安装教程》安装 ADB 工具

打开powershell,执行命令

  adb shell reboot ; adb wait-for-device ; adb shell > .\temp.txt
