¶ Arcs-mini 增加表情教程

¶ 前言

本文用于教学开发者在当前 SDK 中新增一个表情。

¶ 开始之前，请先保证：

SDK 版本在 2.2.0 及以上

可通过命令 git log 查看版本，如果版本过低，请使用命令 git pull --rebase 拉取最新 SDK

已经根据文档《烧录工具安装教程》 安装了ADB工具和烧录工具。

¶ 1. 准备表情资源

目前Arcs-mini不支持直接显示 GIF，您需要先将 GIF 拆成多帧 PNG 后在放入项目中。

¶ 2. 配置表情资源

¶ 3. 关闭云端更新表情

执行命令：

adb shell kv set int user.disable_emoji_update 1

¶ 4. 打包表情资源文件后烧录

打包命令

python3 ./tools/romfs.py pack -i ./res/arcs-mini/emoji -o ./res/arcs-mini/emoji.bin 

烧录地址为：0x00380000

¶ 附：调试指令

¶ 使用本地表情资源

使用本地：adb shell kv set int user.disable_emoji_update  1

查看：adb shell kv get int user.disable_emoji_update 

返回 flash get user.disable_emoji_update :1 success 表示正在使用本地表情资源

恢复默认（使用云端）：adb shell kv del user.disable_emoji_update 

注意如果设置了本地表情资源，擦除后不会重新下载，表情资源不会正常显示
