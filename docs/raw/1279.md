¶ 新增mcp工具：温湿度计-I2C外设

¶ 前言

古法编程的方式实现 语音查询环境温湿度，可参考文档《Arcs-mini开发板增加mcp工具：温湿度计》

本文演示该 Sample 实现让 Agent 代劳。

准备工作：

1.参考文档《AI Agent 编程助手安装教程》安装 AI 编程助手。

2.参考文档《Agent搭建开发环境》 搭建开发环境。

本篇示例源码基于 3.0.2-m3 版本的 SDK。

可通过命令 git log 查看版本，如果版本不一致，请使用命令 git checkout mini-v3.0.2-m3 切到指定 SDK 版本。

¶ Agent 实现功能
