¶ 开发板使用常见问题

¶ Arcs-mini 开发板 和 CSK6 大模型开发套件有什么区别?

回答：

Arcs-mini 开发板构成一套基于 FreeRTOS 的、高度集成且开箱即用的云端大模型语音交互方案，其核心优势在于通过强大的内置 NPU 高效处理音频流，并默认接入小聆 AI 平台，让开发者能以极低的硬件成本和开发门槛，快速构建基于 MCP 服务的智能语音设备原型。

CSK6 大模型开发套件则是一个功能全面的多模态AI开发平台，基于 Zephyr RTOS，不仅提供丰富的本地计算资源（CPU+DSP+NPU）与硬件外设（如触摸屏、多麦克风），支持将视觉、语音等多种 AI 算法直接部署在设备端运行，满足对实时性、隐私保护及功能集成度有更高要求的场景；同时，它也支持接入 MCP 服务，可实现“离线能力+云端大模型”的灵活架构组合。

¶ Arcs 的芯片是否支持双麦+软/硬回采?

回答：

Arcs-mini 开发板硬件上只有1个麦克风，因此不支持双麦。

而 Arcs 芯片支持：单音频输出 + 双音频输入 + 双数字麦(回采）

¶ Arcs-mini 是否支持原来云端配置?

回答：

支持。 Arcs-Mini 开发板与 CSK6 大模型开发套件一样，接入的云端都是聆思平台(LSPlatform)。因此，您原来熟悉的云端配置方法可以继续在 Arcs-Mini 上使用。

¶ 基于 LSPlatform 或者 小聆AI小程序 配置云端模型，和直接使用源码进行二次开发，有啥不同吗?

回答：

LSPlatform / 小聆AI小程序 (云端配置)

能做什么：定制AI角色、上传知识库（如说明书）、配置发音人/唤醒词/热词、集成第三方服务（如地图查询）。

特点：通过网页或小程序操作，技术门槛低，配置即可生效，适合快速为设备更换或升级AI能力。

源码二次开发 (设备端开发)

能做什么：开发新的MCP工具以接入传感器（如温湿度计）、实现新的硬件控制逻辑（如通过串口指令控制外设）。

特点：需要嵌入式开发和修改C语言源码，技术门槛高，需重新编译烧录固件，适合为设备增加全新的硬件功能。

简单总结：

用 LSPlatform，——决定它“知道什么”以及“如何说话”。

做 源码二次开发，赋予它新的“物理技能”。

¶ Arcs-Mini 开发板的 3pin 电池能否只接入 2Pin的电池

回答：

强烈不建议这样做。

3Pin 电池接口并非简单的电源正负极。其第三根引脚是温度监测（NTC）线，用于实时检测电池温度，是实现充电安全保护的关键组件。

如果仅连接电源的 2Pin（正极和负极），将导致丧失温度保护，系统无法感知电池温度，在过充、短路或环境过热时，可能无法及时切断充电电路，存在电池过热、鼓包甚至发生热失控（如起火）的严重安全风险。

为确保安全与设备正常工作，请务必使用配套的、带温度保护功能的 3Pin 电池。切勿为省事或兼容普通 2Pin 电池而牺牲安全。

¶ Arcs-Mini 开发板可以正常进行语音对话，但屏幕不亮，可能是什么原因?

回答：

屏幕排线接触不良（最常见）

原因：开发板在运输、移动或调试过程中，连接屏幕与主板的柔性排线（FPC）可能松动或脱落。

解决方案：关闭设备电源，小心拆开外壳，找到屏幕与主板连接的排线座。将排线轻轻拔出，检查金手指部分是否清洁、无弯曲，然后重新对准插槽插入，确保按压到位并锁紧卡扣。

屏幕硬件损坏

原因：屏幕本身（如液晶面板、背光灯、驱动IC）因静电、物理撞击或内部故障而损坏。

解决方案：在排除上述连接和供电问题后，如果条件允许，可以尝试更换一个确认完好的同型号屏幕进行测试，以确定是否为屏幕本体故障。

¶ Arcs-Mini 开发板配网失败怎么办? / Arcs-Mini 开发板配网时卡在验证 Wi-Fi 账号密码? / Arcs-Mini 开发板配网时搜索不到手机热点的名字? /  Arcs-Mini 开发板配网时卡在正在扫描?

回答：

Arcs-Mini 开发板配网常见问题与解决指南

当您的开发板在配网过程中遇到失败、卡顿或搜索不到网络时，请参照以下流程排查。绝大多数问题可通过确认网络频段、更换热点或遵循特定操作顺序解决。

配网失败或卡在“验证Wi-Fi账号密码”

确认Wi-Fi频段：开发板目前仅支持2.4GHz频段的Wi-Fi。请确保您连接的是路由器的2.4G网络，而非5G网络。

尝试更换网络源：部分路由器有复杂的安全策略（如企业级设置、MAC地址过滤）可能导致连接失败。建议您改用手机的 2.4G 热点作为网络源进行尝试，成功率更高。

如果使用iPhone个人热点，请在手机设置中开启 【最大化兼容性】 选项。

检查密码与信号：确保输入的Wi-Fi密码绝对正确，且设备距离路由器/热点不远，信号良好。

尝试在小程序输入完 Wi-Fi 账号与密码后，在手机设置中将个人热点功能关闭后立即重新打开，然后再返回小程序点击【下一步】进行连接。此操作可刷新热点的广播状态，使其更容易被设备识别。

在配网小程序中搜索不到手机热点的名字

核心原因：手机热点的默认广播设置可能不被设备直接识别。

解决方案：手动填写热点信息，在配网小程序中，不要依赖扫描列表，请直接手动输入您的手机热点名称（SSID）和密码。

小程序一直卡在“正在扫描”，找不到任何网络

核心原因：开发板的蓝牙广播未正常启动，导致小程序无法发现设备。

解决方案：请短按开发板电源键5次，此操作会重新触发蓝牙进入可发现模式。

¶ Arcs-Mini 开发板如何打开调用蓝牙?

回答：

在开发板通电状态下，短按电源键5次。此时，开发板会进入配网模式并开始广播蓝牙信号。

蓝牙功能的用途说明：

开发板的蓝牙功能目前专用于配网，其设计目的是让手机小程序（如“小聆AI”）能发现设备并引导完成Wi-Fi配置。

因此，它无法像普通蓝牙耳机或音箱那样，在手机的蓝牙设置页面中被直接搜索、配对或用于音频传输等通用用途。

¶ 基于LS26芯片开发产品，没有 LCD 显示屏，怎么能配网呀?

回答：

针对基于LS26芯片开发且无LCD屏幕的产品，配网操作可通过蓝牙广播配合手机小程序完成。具体步骤如下：

启动蓝牙广播：

在设备上短按功能键5次。此时设备会进入配网模式，并开始广播蓝牙信号。

手机端连接与配网：

打开手机微信，扫描设备机身或包装上的专属配网二维码贴纸。

或直接在微信搜索并进入“小聆AI”小程序。

小程序会自动搜索并列出附近的设备，点击对应的设备名称即可开始配网流程，根据提示输入Wi-Fi密码即可完成。

总结：无屏设备的配网核心是 “5次按键启动广播 + 手机小程序扫码操作”，无需屏幕交互。

¶ Arcs-Mini 开发板按了一下复位键关机了?

回答：

是的，电池供电时，按下复位键会直接关机。

核心原因：在仅使用电池供电时，按下复位键（RST）的作用被设计为直接切断系统电源，实现快速关机，而非传统的“重启”。

这与USB供电模式下的逻辑不同。在连接USB时，复位键通常执行标准的系统重启功能。

¶ Arcs-Mini 开发板声音可以接大点的喇叭吧?

回答：

支持的，但是更换喇叭之前，可以先使用以下命令调节扬声器增益，把提高增益后看看效果，如果仍然无法满足需求支持更换4Ω3W的扬声器（出厂扬声器为8Ω2W）

使用 ADB 连接设备后，通过 shell 命令调整增益：

adb shell gain <command> [value]

可用命令列表

命令
说明
增益范围 (dB)

 | set_spk
 | 设置扬声器模拟增益
 | -24 到 6 dB，步进 2 dB

 | set_spk_d
 | 设置扬声器数字增益
 | -113 到 30 dB，步进 1 dB

 | print
 | 打印当前所有增益设置
 | -

 | help
 | 显示帮助信息
 | -

命令示例

# 设置扬声器模拟增益为 20 dB
adb shell gain set_spk 20

# 设置扬声器数字增益为 -10 dB
adb shell gain set_spk_d -10

# 查看当前所有增益设置
adb shell gain print

如果调整后会自说自话，可以参考文档《ARCS-MINI 音频增益调试教程》 调整麦克风增益
