¶ ARCS SDK

¶ 概述

ARCS SDK 是一款面向 嵌入式系统 的轻量级软件开发工具包，提供从 底层驱动 → RTOS → 中间件 → 应用能力 的完整软件栈，帮助开发者快速构建稳定、高性能、可扩展的嵌入式产品。

¶ ARCS SDK 主要特性

丰富的驱动支持：提供 UART、GPIO、I2C、SPI、ADC/DAC、PWM、DMA、Flash、Display、Camera、Touch 等 20+ 外设驱动，覆盖常见嵌入式硬件需求。

RTOS 集成：深度集成 FreeRTOS，提供统一的 RTOS 抽象层，降低应用与操作系统的耦合度。

图形界面：内置 LVGL GUI 框架（v7 / v8），支持多种 LCD / EPD 显示设备，满足带屏应用开发需求。

网络功能：支持 HTTP / HTTPS、WebSocket、MQTT 等常用网络协议，适用于物联网与云端连接场景。

多媒体能力：支持 MP3、AAC 音频解码，以及 JPEG、PNG、GIF 图像处理。

USB 支持：集成 TinyUSB 协议栈，简化 USB 设备开发。

算法服务：提供 OCR、TTS、翻译、拼读、语音唤醒等算法与服务能力接口。

开发工具：内置 Shell、日志、单元测试、死机回溯等开发与调试工具。

¶ ARCS 芯片引脚配置工具

👉 Arcs 引脚配置工具

LS-pinmux-tool 是聆思面向 ARCS 芯片 提供的在线引脚配置工具。该工具支持通过 图形化界面完成引脚配置，并自动生成对应的 pinmux 引脚配置代码，可在进行 自定义硬件板型设计 时显著提升开发效率，降低配置出错风险。

开发者可根据实际硬件需求，自定义板级版型，并通过 ls-pinmux-tool 完成引脚配置与代码生成。
