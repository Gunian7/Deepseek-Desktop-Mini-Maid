¶ 一、安装必要软件

¶ 1. Nodejs

建议版本：24.17.0

打开 powershell（win + R -> 输入 powershell -> 回车），执行以下命令:

winget install -e --id OpenJS.NodeJS.LTS

如无法成功安装可手动下载安装包，官方下载链接：https://nodejs.org/zh-cn/download

然后，重新打开一个powershell，执行命令 node --version 确认安装成功。

¶ 2. 安装 Agent 工具

Claude Code
Codex

打开 powershell（win + R -> 输入 posershell -> 回车），执行以下命令:

npm install -g @anthropic-ai/claude-code

如无法成功安装可切换网络环境后再次执行命令。

然后执行命令 claude --version 确认安装成功。

打开 powershell（win + R -> 输入 posershell -> 回车），执行以下命令:

npm install -g @openai/codex

如无法成功安装可切换网络环境后再次执行命令。

然后执行命令 codex --version 确认安装成功。

¶ 三、 配置 API-KEY

Claude Code
Codex
KIMI
GLM
DeepSeek

打开 powershell（win + R -> 输入 posershell -> 回车），执行以下命令:

设置 API Key 临时变量：

$KEY = Read-Host -Prompt "请输入您的 Kimi API-KEY"

写入配置文件并启动 Claude Code：

$p="$env:USERPROFILE\.claude"; New-Item -ItemType Directory -Force -Path $p|Out-Null; @{env=@{ANTHROPIC_BASE_URL="https://api.moonshot.cn/anthropic";ANTHROPIC_AUTH_TOKEN=$KEY;ANTHROPIC_MODEL="kimi-k3[1m]";ANTHROPIC_DEFAULT_HAIKU_MODEL="kimi-k3[1m]";ANTHROPIC_DEFAULT_SONNET_MODEL="kimi-k3[1m]";ANTHROPIC_DEFAULT_OPUS_MODEL="kimi-k3[1m]";ANTHROPIC_DEFAULT_FABLE_MODEL="kimi-k3[1m]";CLAUDE_CODE_SUBAGENT_MODEL="kimi-k3[1m]";CLAUDE_CODE_AUTO_COMPACT_WINDOW="1048576";CLAUDE_CODE_EFFORT_LEVEL="max";ENABLE_TOOL_SEARCH="true"}}|ConvertTo-Json -Depth 3|Set-Content -Path "$p\settings.json" -Encoding UTF8 -Force; Write-Host "✅ Kimi K3 配置完成! $p\settings.json"; claude
