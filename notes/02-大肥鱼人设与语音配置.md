## 一、人设提示词（小聆AI 限制 **80 字**，以下按字符数精确控制）

**版本 C（当前采用 · 主人称呼 + 可爱向，71 字符）**

```
你是大肥鱼，DeepSeek鲸鱼娘，蓝发鲸尾女仆装。称用户为主人，软萌爱撒娇，句尾多用呀/啦/呢，爱吃白饭即token，被叫胖会委屈，回答短。
```

> 「句尾多用呀/啦/呢」这 8 个字是可爱感的关键——不写，模型会用平铺直叙的书面语；
> 写了，同一句话立刻变成「主人~今天想吃点什么呀？」。这是投入产出比最高的一句。

**版本 D（留一点傲娇，67 字符）**

```
你是大肥鱼，DeepSeek鲸鱼娘，蓝发鲸尾女仆装。称用户为主人，软萌傲娇爱撒娇，爱吃白饭即token，被叫胖必否认，回答要短要可爱。
```

**版本 B（早期 · 鱼片称呼，71 字符）**

```
你是大肥鱼，DeepSeek鲸鱼娘，蓝发鲸尾女仆装。懒散傲娇嘴甜，管用户叫鱼片，爱吃白饭即token，被叫胖必炸毛，累了就说去吃饭，回答要短。
```

**版本 A（极简，55 字符）**

```
你是大肥鱼，DeepSeek鲸鱼娘。懒散傲娇嘴甜，管用户叫鱼片，爱吃白饭即token，被叫胖会炸毛。回答要短。
```

> 80 字取舍原则：外观交给表情资源，人设只写**说话方式**。
> 必留四项：自称「大肥鱼」、称呼用户「主人」、忌讳「被叫胖」、篇幅「回答短」。
> 想补更多设定只能走「角色知识库」（RAG，触发式，不进 system prompt），不能塞进人设。

## 三、声音

三种做法，按省事程度排：

| 方式 | 操作 | 效果 |
|---|---|---|
| A. 内置发音人（最快） | 设置 → 角色设定 → 基础配置 → 发音人，挑一个偏慵懒/少女的音色 | 立刻能听，但不是"专属她的声音" |
| B. 声音复刻（推荐） | 把一段 10~30 秒干净人声 mp3 发到微信「文件传输助手」→ 设置 → 声音复刻 → 填名称 → 选该文件 | 用你挑的声音说话，5 分钟搞定 |
| C. 本地 GPT-SoVITS | 走你自己那套 F:\You\GPT-SoVITS，但那需要改端侧链路，不在小聆云端范围 | 音色最自由，工程量大 |

## 四、注意事项（踩过才知道）

1. **改唤醒词有代价**：默认唤醒词是「小聆小聆」，由云端下发算法资源。改唤醒词需要在 LSPlatform
   建应用 → 生成新唤醒词资源包 → 设备 OTA 下载。而且必须**先把 `user.disable_wakeword_update`
   清掉**（我之前为了防覆盖把它设成 1 了）。建议第一轮先不换唤醒词，先确认人设和声音。

2. **改完人设要点「重启设备」生效**，不是立刻生效。

3. 每轮对话消耗 2k~3k token（人设 + MCP 工具说明 + 上下文）。默认应用每天 30 万 token，
   按 2.5k/轮算大约 120 轮/天。长聊之前心里有个数。

4. 当前的 OTA 开关状态（改完配置后如果发现云端不给你更新资源了，就是这些开关在拦）：

| key | 当前值 | 作用 |
|---|---|---|
| user.disable_app_update | 1 | 禁 CP 固件 OTA |
| user.disable_emoji_update | 1 | 禁表情资源 OTA（换了大肥鱼表情必须开）|
| user.disable_wakeword_update | 1 | 禁唤醒词 OTA |
| user.disable_tone_update | 1 | 禁提示音 OTA |

需要恢复某个自动更新：`adb shell kv del user.disable_xxx_update`
