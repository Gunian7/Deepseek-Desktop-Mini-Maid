Mini3 的 PA00 同时是 EXT4G_PWR。本示例把它切换为 PWM 后，不再提供 4G 电源控制功能。

¶ 1. 服务层与构建接入

舵机服务位于：

apps/arcs-mini/services/service_mg90s.c

apps/arcs-mini/services/service_mg90s.h

服务文件在 apps/arcs-mini/services/CMakeLists.txt 中参与编译，提供初始化、启动、停止和切换运行状态接口。

¶ 2. 按板型选择 PWM 引脚和通道

Mini2 保持原来的 PA06/CH6，Mini3 使用 PA00/CH0：

#define MG90S_PWM_PAD         CSK_IOMUX_PAD_A
#define MG90S_PWM_FUNC        CSK_IOMUX_FUNC_ALTER12

#ifdef CONFIG_BOARD_ARCS_MINI3
#define MG90S_PWM_PIN         0U
#define MG90S_PWM_CHANNEL     0U
#define MG90S_PWM_PIN_NAME    "PA00"
#else
#define MG90S_PWM_PIN         6U
#define MG90S_PWM_CHANNEL     6U
#define MG90S_PWM_PIN_NAME    "PA06"
#endif

初始化时获取 pwm0，把目标引脚配置为 Function 12，再配置对应逻辑通道：

s_pwm_dev = lisa_device_get("pwm0");
IOMuxManager_PinConfigure(MG90S_PWM_PAD, MG90S_PWM_PIN, MG90S_PWM_FUNC);

lisa_pwm_config_t config = {
    .polarity = LISA_PWM_POLARITY_NORMAL,
};
lisa_pwm_configure(s_pwm_dev, MG90S_PWM_CHANNEL, &config);

¶ 3. 舵机脉宽与速度控制

服务使用约 53Hz 的 PWM，并以 1.5ms 作为停止脉宽：

顺时针最大速度：约 1.3ms。

停止：约 1.5ms。

逆时针最大速度：约 1.7ms。

speed 会换算为目标脉宽，再转换成 LISA PWM 驱动需要的整数占空比。由于整数占空比会产生量化，代码会避免非零速度最终仍等于停止占空比。

¶ 4. 按键测试入口

apps/arcs-mini/button/app_button.c 在电源键四击事件中调用 service_mg90s_toggle()：第一次四击开始旋转，再次四击停止。这个入口可用于在接入云端 MCP 前检查供电、共地和 PWM 输出。

¶ 5. 注册 MCP 工具

MCP 工具位于 apps/arcs-mini/mcp-tools/mcp_tool_mg90s.c，支持：

必填参数 direction：cw 或 ccw。

可选参数 speed：low、mid、high、stop 或 0~100。

MCP_TOOL_DEFINE(mg90s_control, mg90s_control_list, mg90s_control_call);

工具描述会根据板型显示 Mini2 的 PA06/CH6 或 Mini3 的 PA00/CH0，但注册名保持不变。

¶ 6. 编译验证

.\build.ps1 -S .\apps\arcs-mini -B build-mg90s-mini -DBOARD=arcs_mini
.\build.ps1 -S .\apps\arcs-mini -B build-mg90s-mini3 -DBOARD=arcs_mini3

两个板型均应生成 arcs-mini.bin、LPK、OTA 和 combined HEX。实板接线时舵机建议使用独立 5V 电源，并务必与开发板共地。
