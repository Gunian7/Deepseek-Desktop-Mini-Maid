¶ 三、设备开启4G网络环境

打开powershell（win + R -> 输入 posershell -> 回车）后，执行命令

adb shell kv set int user.network_mode 1

重启 Arcs-mini 开发板，执行命令

adb shell reboot

注意，请先检查 SIM 卡是否有流量。

¶ 五、关于定位

SDK版本需在 2.5.1 及以上

可通过命令 git log 查看版本，如果版本过低，请使用命令 git pull --rebase 拉取最新 SDK

可通过函数lisa_modem_start_gnss()开启4G模组定位，然后通过函数lisa_modem_get_gps_location()获取到经纬度。

使用示例：

#include "lisa_modem_module.h"

if (!lisa_modem_start_gnss()) {
    LISA_LOGW(TAG, "GPS GNSS start failed");
} 

double lat = 0.0, lon = 0.0;
if (lisa_modem_get_gps_location(&lat, &lon)) {
    LISA_LOGI(TAG, "GPS location: lat=%.6f, lon=%.6f", lat, lon);
} else {
    LISA_LOGW(TAG, "GPS location not fixed yet");
}

GPS定位在室内场景下不可用。

可在室外在尝试GPS定位(首次定位大概需要1min左右），或者改用LBS定位（基站定位），增加AT指令即可。

具体可参考手册：《lbs用户手册_4g系列_v1.6.4.pdf》 、《gnss用户手册_4g系列_primary.pdf》
